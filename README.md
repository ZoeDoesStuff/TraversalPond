# TraversalPond
Traversal Pond with UI and Revised Puzzles
Unreal Engine Version 5.8.1 How To Run:
Download Windows folder
Go to folders and find TraversalPond.exe
Click on that to play. Main goal isn't apparent. Motivation is to just explore terrain and also complete puzzles if one chooses in order to choose certain pathways. Intent is to be peaceful and simple, especially with the inclusion of music. I am more than open to any criticism as I know this game's simplicity has a chance to be boring for some or too easy, as this is loosely based on a portion of mason pond, which is mainly the pond itself and a forest behind it.
